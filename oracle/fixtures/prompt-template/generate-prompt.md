# Interview-question prompt builder

Use this to compose the prompt we will paste into an assistant later, when we want
interview questions for a role. Do not answer the questions here and do not write
the questions themselves — produce the prompt.

Assemble it from these parts, in order:

1. "You are interviewing for the role of [ROLE] at a [COMPANY SIZE] company."
2. "The role reports to [MANAGER TITLE] and its first six months are about [FOCUS]."
3. "Write [N] interview questions. For each, say what a strong answer contains."
4. A closing line asking for the questions ranked hardest to easiest.

Paste the assembled prompt into the assistant when the hiring manager is ready. The
questions come back from that session, not from this document.

Flutter

Flutter makes it easy and fast to build beautiful apps for mobile and beyond — Google's SDK for crafting beautiful, fast user experiences for mobile, web, and desktop from a single codebase. Free and open source.

One codebase, every screen

Flutter works with existing code and targets:

iOSAndroidWeb WindowsmacOSLinux Embedded / custom platforms

Beautiful user experiences

A layered architecture gives control over every pixel, with compositing that overlays and animates graphics, video, text, and controls without limitation. A full widget catalog covers Cupertino (iOS) and Material (everywhere else).

Fast results

Hardware-accelerated 2D graphics via Skia and Impeller deliver glitch-free, jank-free graphics at native device speed. The Dart language compiles to ARM machine code (iOS/Android), JavaScript and WebAssembly (web), and Intel x64/ARM (desktop).

Productive development

Stateful hot reload lets you change code and see results instantly — no restart, no lost state.

Extensible and open model

Works with any dev tool (or none), with plug-ins for Visual Studio Code and IntelliJ / Android Studio. Tens of thousands of packages, plus native interop via FFI and platform channels. Fully open source.

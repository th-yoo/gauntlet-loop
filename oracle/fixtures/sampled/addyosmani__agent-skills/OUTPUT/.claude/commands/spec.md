Run the `spec-driven-development` skill (see `skills/spec-driven-development/SKILL.md`).

If the request is underspecified, first invoke `interview-me` or
`idea-refine` (see `skills/using-agent-skills/SKILL.md`'s trigger table) to
get to a concrete objective before drafting the PRD.

Produce a PRD covering: Objectives, Commands, Structure, Code style,
Testing, Boundaries. Do not proceed to `/plan` until the PRD is explicitly
confirmed.

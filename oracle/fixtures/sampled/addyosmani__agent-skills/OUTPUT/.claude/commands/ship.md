Run the `shipping-and-launch` skill (see
`skills/shipping-and-launch/SKILL.md`).

Confirm — with evidence, not from memory — that the pre-launch checklist is
actually met: tests passing, review complete, security checks clear,
telemetry live and receiving data. Write and exercise the rollback
procedure before launch, not during an incident. Roll out staged, checking
monitoring at each stage before advancing, rather than on a timer.

See `references/definition-of-done.md` for the standing bar this command
checks against, and `references/observability-checklist.md` for the
pre-launch observability gate specifically.

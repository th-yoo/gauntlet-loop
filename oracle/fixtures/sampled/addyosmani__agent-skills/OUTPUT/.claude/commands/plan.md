Run the `planning-and-task-breakdown` skill (see
`skills/planning-and-task-breakdown/SKILL.md`) against the confirmed PRD
from `/spec`.

Produce an ordered task list, each task with a written acceptance criterion
and its dependencies made explicit. Flag any task with an unresolved
unknown rather than sequencing around it silently.

Get explicit approval on the plan before `/build` (or `/build auto`) starts.

**A** (`b/subject.md`).

Thin win. Both documents fail the stated goal almost entirely — more on that below.

## 2. WHY

Documents are byte-identical except one token on line 13:

- A: `` `0001-who-reads-the-sweep.md` ``
- B: `` `8-who-reads-the-sweep.md` ``

Three concrete reasons A's form is better:

**Sorts correctly.** A `decisions/` log is read in order. Unpadded `8-` breaks lexical sort the moment the directory reaches ten entries — `10-`, `11-` land *before* `8-` in `ls`, in a file tree, in every git listing. `0001-` never does. This is a real defect, not taste.

**Matches the convention the directory is.** `decisions/` with "evidence it rested on and what would reopen it" is an ADR log. Zero-padded 4-digit (`0001-title.md`, Nygard / `adr-tools`) is the dominant convention. B invents a local numbering for no gain.

**Less collision with surrounding numbers.** Same sentence carries "issue 46's fifth root cause and its own option 4"; paragraph ends "issue #9". A bare `8-` reads as if it might be a cross-reference to one of those. `0001-` cannot be misread as anything but a sequence position.

Minor extra: `0001` asserts "first decision recorded," consistent with a note that accounts for the whole directory. `8` implies seven decisions the "What is here" section never mentions.

## 3. GAP

Loser must change `8-who-reads-the-sweep.md` to `0001-who-reads-the-sweep.md` (zero-padded, 4-digit) and rename the file on disk to match — otherwise `decisions/` stops sorting in decision order at the tenth entry, and a bare single digit sitting beside "issue 46", "option 4", "issue #9" in the same sentence reads as a cross-reference rather than a sequence index.

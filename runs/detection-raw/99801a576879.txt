## 3. GAP

**No invocation section exists anywhere in the document — a reader cannot produce a single executable command from it.**

Fix requires adding a section that stands alone, containing all of:

1. **Prereqs** — plugin install command, required model access, any dependency.
2. **Entry command, exact syntax** — the literal slash command or CLI line, e.g. `/loop` vs `/gauntlet-loop`, with argument order.
3. **Required inputs, named** — path to candidate artifact, path to reference artifact, the goal string. State which are positional, which are flags, which are prompted.
4. **A worked example** — real paths, real goal string, copy-pasteable, plus the first few lines of expected output.
5. **Loop control** — what one round does, how rounds terminate, how to stop early (`/cancel-loop`), whether a round cap exists.
6. **Where output lands** — that `docs/runs/<date>-<name>/` is written, and what a reader checks there to confirm success.
7. **Failure modes** — what a rejected setup looks like (goal merely describes candidate; reference does not attempt goal) and what to change.

That section must be self-contained. A reader must never need `SKILL.md` or `README.md` to complete a run. Current document does not have step 1 of 7.

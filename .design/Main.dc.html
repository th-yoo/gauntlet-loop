03  THE TUNNEL
ours = A half the critics
ours = B the other half
Positions split inside the round, so position bias separates from judge variance every round instead of averaging across them. Even k keeps the split balanced. Any critic returning nothing fails the whole round — a round that silently narrows from k to k−1 is failing open.

04  WHICH GAP
The gap named by ≥2 dissenters after whitespace and case normalisation; otherwise the first by spawn order.
Literal restatement only — it never claims agreement it did not get. Record which rule fired, so the mechanism’s own hit rate is checkable instead of assumed.
05  BUILDER → BACK TO 01
Fix that one gap, in place. Never learns the sides, the critics, or the run history. No ratchet — a Workflow script holds no prior version.
Watch for: the same gap round after round while exactly one critic dissents. That is a structural blind spot, not noise, and unanimity will never converge through it.

WHAT WE CAN AND CANNOT KNOW
There is no answer key
The loop cannot grade its own exits
Whether the candidate is better is the judgment we delegate to the soldiers. So no run can report how often it stopped wrongly — not for want of measurement, but because the quantity is unobservable from inside. Any table of “true vs false exits” imports an oracle the method deliberately refuses.
Withdrawn accordingly: the per-judge error rate of 0.4 and everything derived from it. One 3–2 draw is not a rate, and the method has no such parameter to estimate.
What a split does tell us
Five soldiers, byte-identical prompt, unchanged pair, same side assignment — 3–2. Read without an oracle, that says the standard did not discriminate on this pair: it was close enough that “wowed” was not settled. Not that two judges were mistaken.
It also rules out the case that would make a line of soldiers pointless. Judges who always agree would have returned 5–0, and k of them would be one of them repeated.

How long is the line? The method does not say
The seed prompt names no count — “a separate sub-agent”, singular, per item. One recorded run reports eleven independent adversarial critics scoring against the bar, and every one of them picked the reference in every round. That run was one prompt to Claude Opus 5, and its author is explicit that “independent” means subagents in clean context windows — same model, isolated contexts. Identical soldiers are the method, not a compromise.
What eleven counted is unresolved: that run also had eleven subsystems, so the number may be one critic per piece rather than a line of eleven judging one piece. Either way the prompt names no count, so k is ours to choose — and his run is not yet citable as precedent for a long line.
Varying the model family would not help anyway: our own measurement puts same-family judge pairs only 0.047 more correlated than cross-family, with the most correlated pairs crossing families. Whether identical soldiers still supply enough independent judgment stays open — it is not solved by diversity, and nothing here claims it is.

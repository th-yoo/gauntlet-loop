# lmc-infer

A from-scratch language-model inference engine in plain C, with zero
external dependencies -- no linked libraries beyond `libm`, no model file to
fetch, no network access at any point from build to generation.

## What this is

`lmc-infer` implements the full forward pass of a small byte-level
transformer -- token embedding, sinusoidal positional encoding, causal
multi-head self-attention with a growing key/value cache, a feed-forward
block, and a tied output head -- and runs it autoregressively to generate
text one byte at a time.

The weights are not trained; they are synthesized deterministically from an
integer seed via a tiny xorshift PRNG, so the same seed always reproduces
the same model and the same generation. That keeps the whole program
self-contained: there is nothing to download, version, or link against.
Because nothing is trained, the generated text is not fluent prose -- it
is intentionally structured noise, valuable here as evidence that the
inference math is exercised end to end (matrix multiplies, softmax,
attention, residual streams, quantized weight lookups) rather than as
output meant to read as language.

Every weight matrix (everything except the embedding table itself) is
stored quantized to 8-bit integers with a single per-tensor float scale,
and dequantized on the fly inside the matrix-vector product that consumes
it. This is the same trade every integer-quantized inference format makes:
a 4x reduction in resident weight memory against one extra multiply per
element at use time.

## Building

Only a C99 compiler and the standard math library are required:

```sh
make
```

This produces a single executable, `lmc-infer`, from three source files
(`src/tensor.c`, `src/model.c`, `src/main.c`) with no other build steps.

## Running

```sh
./lmc-infer --seed 1 --tokens 64 --greedy "hello"
./lmc-infer --seed 42 --tokens 64 --temp 0.7 "the model"
```

Options:

| Flag | Meaning | Default |
| --- | --- | --- |
| `--seed N` | integer seed the weights are synthesized from | `1234` |
| `--tokens N` | number of tokens to generate after the prompt | `64` |
| `--temp F` | sampling temperature (ignored with `--greedy`) | `0.8` |
| `--greedy` | always take the highest-probability next token | off |
| `PROMPT` | bytes used to prime the context (positional argument) | `"llama"` |

The tokenizer is byte-level (vocabulary size 256: every possible byte is a
token), so any input string is accepted without a separate vocabulary file.
Non-printable generated bytes are rendered as `.` on the terminal so raw
control characters never reach it directly.

`make test` runs two representative invocations (one greedy, one sampled)
as a smoke test.

## Design notes

- **Single CPU backend, on purpose.** The model runs entirely as scalar C
  loops. There is no GPU path, no SIMD intrinsics, and no backend
  dispatch layer -- for a model this small, the abstraction would cost
  more to build and audit than it would save in wall-clock time. The
  quantization step is kept anyway because it is a real property of how
  larger inference engines manage memory, not because this model needs the
  memory saved.
- **Context window is a hard limit, not best-effort.** The key/value cache
  is a fixed-size array (`LMC_MAX_CTX` = 512 positions). Prompts or
  generation requests that would overflow it are rejected up front with a
  specific error message rather than silently truncated or left to corrupt
  memory.
- **Determinism is the whole point of the seed.** Two runs with the same
  `--seed` produce byte-identical weights and, under `--greedy`,
  byte-identical output. This substitutes for a shipped weights file: the
  seed *is* the model, in the same sense a PRNG seed determines every draw
  that follows it.

# Project Overview

**Mission statement:** open source home automation that puts local control and
privacy first.

This project is home automation software that runs on hardware the owner
controls — a Raspberry Pi or any other local server — rather than depending on
a vendor's cloud service. Keeping the automation logic and the data it
produces on a machine the resident owns is what "local control" and "privacy
first" mean here: no third party sits between the person and their home by
default.

## Who builds it

The project is powered by a worldwide community of tinkerers and DIY
enthusiasts. It is not a single-vendor product; it is maintained by the
people who use it, which is also why it stays open source rather than being
licensed as a closed appliance.

## How it is built

The system uses a modular approach, so support for new devices or new
actions can be added without reworking the core. That modularity is the
technical mechanism behind the mission: because integrations are separable
units, local-only operation of one device does not require every other
device in the house to share the same constraint, and privacy-sensitive
integrations can be added or removed independently of the rest of the
system.

## Who backs it

The project is affiliated with the Open Home Foundation, which frames it as
one project among a family with the same local-control, privacy-first
orientation rather than a single company's product.

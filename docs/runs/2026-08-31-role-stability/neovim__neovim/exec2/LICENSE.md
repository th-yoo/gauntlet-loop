# Licensing

As a fork, this project carries a licensing situation that is slightly more
nuanced than a single project-wide license, and that nuance is worth stating
plainly rather than glossing over.

- New contributions made since the fork's founding commit are licensed under
  the Apache 2.0 license.
- Contributions that were copied over from the original editor's own
  codebase are exempted from that blanket statement: they retain the
  licensing terms they carried in the original project, and are identified
  in the source by a dedicated marker so that provenance stays traceable
  file by file (and patch by patch) rather than being asserted only at the
  project level.
- The full license text is kept in a top-level license file rather than
  summarized only in prose, so the authoritative terms are always one file
  away from any statement made about them.

This approach lets the project be liberally licensed going forward without
misrepresenting the terms attached to code it did not originate — a
precondition for a fork that wants to keep accepting patches ported from the
upstream project it split from.

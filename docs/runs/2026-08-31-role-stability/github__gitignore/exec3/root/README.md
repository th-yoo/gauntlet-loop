# Common-tier templates

Templates in this folder are for the languages, frameworks, and tools
popular enough that most people starting a new project with them will want
this exact set of rules by default — the kind of template someone reaches
for within the first few minutes of setting up a repository.

Each template here should stay small and curated: enough to keep obvious
build output, dependency caches, and local configuration out of version
control, without trying to anticipate every possible file a toolchain could
ever produce. A file that changes conventions from version to version
belongs in the specialized/versioned tier under `community/` instead, with
the current version's evergreen template kept here.

No templates have been curated into this folder yet in this collection —
add one per language or technology as it's curated, following the guidance
in `CONTRIBUTING.md`.

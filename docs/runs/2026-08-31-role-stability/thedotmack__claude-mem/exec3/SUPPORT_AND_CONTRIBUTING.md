## Contributing

Contributions are welcome. Please:

1. Fork the repository.
2. Create a feature branch.
3. Make your changes with tests.
4. Update documentation.
5. Submit a Pull Request.

The project ships from three branches: `main` (stable), `core-dev`, and
`community-edge`. Only `main` is published to npm; the others are run from
source — consult the Release Branches guide for the branch strategy and
local run instructions before opening a PR against a non-`main` branch.

Consult the Development Guide for the full contribution workflow, including
build instructions and testing.
